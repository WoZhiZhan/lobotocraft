Problem
全局逆流阶段、单体限时融毁和核心抑制条件互相泄漏，鸟蛋融毁可能在下一 tick 被清空且不显示。
Solution
拆分 Stage Context、不可变 Definition 和持久化 Instance，由一个 Deep Module 统一生命周期。

Benefits

  • locality：创建、计时、解决、失败集中
  • leverage：新原因复用一个 Interface
  • 测试只跨生命周期 Seam
  • 存档与监控读取同一状态投影
  • Binah 可保留原因而不虚构行为
  • 旧实例保留 Definition 版本快照
风险：不要设计一个公开的巨型 flags 模板。Interface 应保持小，原因差异留在 Implementation；旧存档先兼容读取 Target / Deadline / Level / TargetCode。

Top recommendation

深化融毁生命周期 Module

先引入类型和旧 NBT 读取，再逐个迁移逆流、鸟蛋、监控和工作完成路径；这能以中等迁移风险获得最高 locality 与 leverage。
