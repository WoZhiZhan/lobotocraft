# Chesed 核心抑制实现记录

## 源码结论

原作 `ChesedBossBase` 在核心抑制开始时为所有员工附加 `ChesedBossBuf`。该效果只改变受伤结算：当伤害类型属于当前危险类型时，伤害倍率为 5，否则为 1。

危险类型由逆卡巴拉熔毁等级重新抽取：

- 开始时抽取 1 种红、白或黑伤害；蓝（原作 Pale）不会出现在第一阶段。
- 熔毁等级 1、3、4、6、7 等普通变化会重新抽取当前阶段数量。
- 熔毁等级 2 后进入第二阶段，抽取 2 种，蓝伤从此可能出现。
- 熔毁等级 5 后进入第三阶段，抽取 3 种。
- 第一阶段的单个危险类型不能与上一次相同。
- 能源配额完成且熔毁等级达到 8 时完成核心抑制。

原作的核心实体不可攻击，也没有独立生命条；它只是福利部核心房间中的阶段展示对象。本 mod 沿用现有核心抑制生命周期和 HUD，不新增无 gameplay 的实体。

## 本 mod 映射

- `ChesedEncounterData` 持久化当前危险类型掩码和已处理的熔毁等级。
- `ChesedEncounterService` 通过 `CoreSuppressionEncounter` 接入开始、结束、服务器启动清理、熔毁通知和伤害倍率。
- `CoreSuppressionDamageHooks` 在红、白、黑、蓝伤害的最终结算处统一应用倍率，蓝伤的生命百分比部分也会完整放大。
- 客户端同步机制状态并在 HUD 显示四种危险类型；完整视觉模式使用独立的 `core_chesed_rain` 后处理。雨幕严格映射原作 `CameraFilterPack_Atmosphere_Rain_Pro`：使用原版 1024×1024 RGB 打包贴图，R 通道生成五层雨幕，B 通道结合场景边缘生成落点飞溅，G 通道生成风暴明灭；开始和阶段切换时按原作在 3 秒内将速度、尺寸、强度和水滴量从爆发值插值到常驻值。按当前设计要求只保留微弱深蓝滤镜，不启用原作黑色暗角或场景 UV 扭曲。Chesed 后处理在 GUI 前执行，HUD 使用原作 `ChesedBossUI` 的四向内聚 Sprite 和中央 Chesed 核心图标。
- 音乐沿用其他上层核心抑制的通用阶段切换：阶段 0 播放设施警报，阶段 1 播放 `core.chesed_1`，阶段 2 播放 `core.chesed_2`；阶段变化只在切换瞬间启动对应曲目。

## 有意保留的差异

原作的 `ChesedCoreScript` 只是不可攻击的 Unity 展示对象。本 mod 当前没有福利部核心展示模型，因此不生成额外实体；这不影响伤害、阶段、完成条件、音乐或 HUD 机制。
