# 砸地虚假方块二版（2026-10-05）

用户明确：“有同类型材质的虚假方块从地面震起来再落下后自然消失”，且要求重量感、尽量保留性能。本条取代首版旋转碎块缩小消失的表现，不改变E.G.O限定或战斗。

## 改动

- 保持源地板格中心，按BlockPos去重：一格最多一块虚假立方体，不横向漂移。
- 从源BlockState模型六个面的quad缓存贴图和对应染色，不再将粒子图标及一种染色复制到六面。非完整碰撞块、设备/方块实体等原筛选不变。
- 立方体固定体积，只短暂小倾角，起点/落点归正；不做无限翻滚。
- 重力0.035→0.09，默认约7–11 tick腾空，峰高约0.5–1.2格；降落变快，落地后停止倾斜。保持两拍出场节奏，不改变攻击时序。
- 低天花板限制初速度，让整条抛物线变低，而不是原先 `min(maxHeight, height)` 截平顶点导致悬停。
- 落地停留2 tick，再用5 tick透明度衰减，体积不缩小。最高寿命26→22 tick。
- 可见模型底面按旋转后最低点与地面接触，避免落地后半埋或停在半空。

## 性能与边界

仍是客户端粒子，六面24顶点复用地形图集批量绘制；每次最多20块、客户端最多64块、原粒子质量/距离降级、卸载清理不变。去重可能使实际生成数少于采样上限。

模型贴图/染色和有限天花板探测只在生成时进行；无逐帧模型查询、无逐tick方块碰撞或实体物理、无服务器逐块同步。渲染复用8个顶点与四元数，不新增每帧几何集合分配。

不修改真实地板、库存、掉落、伤害或包布局。协议保持43，横斩/突刺试验不受影响。
