## 同步与维护

- 一个strict-clientbound技能事件包：开始、8tick低频快照、换位、打击、结束；目标位置在结算前采样，避免镇压回收后把斩痕画到收容单元。
- 每次施放用单调ID及实体UUID区分；纯状态容器限制8个施放、24个短痕、32个结束ID。重复Cue/旧施放/结束后晚到快照不复活预警；实体失效、死亡、取消、结束及世界切换清理。
- 移除生产三特殊技能的逐tick服务端粒子广播。关闭增强时，旧几何粒子算法由客户端通过共享ParticleSink重放，保留旧风格；单tick预算192，质量与距离降级，因此不是逐像素/逐随机位置相同的旧画面。
- 新开关 `[visuals] geburahSpecialVisuals`，默认true。`/lobotocraft_client geburah_special_visuals false`切旧粒子风格；不关闭横斩/突刺试验或砸地二版。客户端保存持久化需实机验证。
- 顶点颜色批量绘制、保留深度测试；64格外不绘制。增强模式不再每帧建立原粒子群，仅在关键节点补少量尘烟。硬预算不是已测得FPS提升，GPU帧耗待测。
