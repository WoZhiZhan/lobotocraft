# 加时赛五项根因修复（2026-10-04）

本轮范围：斯卡蒂声波音效、棘刺公交远程套装、狼／红帽低生命无差别攻击、尸山武器特殊攻击。未提交Git、未打发行JAR。当前工作区此前未提交修改均保留。

## 实际根因与修改

### 狼／红帽：攻击意图没有经过公共许可

目标范围原已包含员工，但 `FacilityCombatRules.blocksEmployeeFriendlyFire` 无法区分普通攻击与本次低血量无差别攻击。员工使用 `ServerPlayer`，其原版PvP/队伍检查发生在Forge伤害事件之前；只修改Forge门仍不能修好。

最小共同改动：

- `AttackDamage`保存不可变的本次 `Targeting.NORMAL/INDISCRIMINATE`，默认普通。
- 武器严格低于50%生命时声明无差别。普通伤害源不因玩家拿着相同武器或低生命而获得许可。
- 公共友伤判定及 `ServerPlayer.hurt` 现有 `canHarmPlayer` redirect均读取同一份意图。没有替换责任实体，没有改服务器PvP配置，没有跳过无敌/死亡/创造/观察者或异想体收容战斗规则。
- 延迟技能持有发动时的伤害源，DOT随原来源和颜色保存意图，旧存档缺省普通；普通刷新覆盖旧许可，不是永久OR。
- 最后复跑暴露一次狼右键漏击：旧实现按异步回调次数恰好4/15结算，而计数在异步线程增加、命中回调再切主线程，可能跳过等值。仅该技能改为游戏时刻27/38两个一次性命中点，正常结束时补结算到期段；取消/无效目标不走结束补击。实际延迟回归同时要求两段伤害事件，未改伤害、未重写公共计时器。
- 拒绝的命中不施加DOT、减速或火铳猎物；正常友伤拒绝的狼右键不挂移动锁。
- 红帽原恰好50%也暴怒，按反馈“低于”改为与狼一致的严格小于。其他攻速、伤害数值未调整。

真实武器验证：狼直接/挥击/延迟；红帽短刀主命中/范围/火铳；PvP关闭下低生命可伤、恰好50%不伤；延迟发动后回血换武器不丢许可；DOT真实存读后许可保留、普通刷新后失去许可；拒绝火铳不附猎物。测试服务器临时PvP修改仅供对照并恢复，不是生产修复。

### 棘刺公交：颜色不等于远程，取消伤害不等于反射

原 `DamageHelper.isRangedAttack` 主要枚举原版伤害类型。绿黎明、亡蝶、红帽粒子枪、斯卡蒂等使用颜色伤害直接结算，未携带远程身份。终末鸟光球甚至不继承原版 `Projectile`。

- `AttackDamage.Delivery`与目标许可独立：DIRECT/RANGED，不借用颜色作远程分类。
- 原版投射物和模组远程技能进入同一套装资格检查。
- 原版投射物在碰撞入口反向速度、换责任归属并继续飞行；终末鸟光球通过 `DeflectableAttack` 保留自身导航，改追原发射者，归属防御者。
- 非实体声波/粒子枪没有可以改速度的弹体，只防护该次远程技能，不伪造飞回的实体。
- 斯卡蒂声波包含绕过普通伤害的额外直接扣精神，须连同整个技能一起防护；亡蝶的附带效果同样不能在阻挡后执行。
- 既有海嗣喷吐投射物事件尊重已经被跳过的反射碰撞，不在后续事件中把反射箭删掉。
- 五个反馈指定生产入口均逐个跑：绿黎明特殊射击、亡蝶锥形大招、红帽火铳、斯卡蒂声波、终末鸟光球。原版箭实际速度、归属、存活和普通近战能受伤也独立验证。

### 斯卡蒂音效：作用范围与声音位置脱节

注册、调用、OGG均存在。`ffprobe`读取 `isharmla_beam.ogg` 为44.1kHz、双声道、1.410612秒；`ffmpeg volumedetect`检测平均约-27dB、峰值约-11.7dB，不是静音文件。

旧声波命中在本体40格外可发生，但命中声以2倍音量（常规传播约32格）仍只从本体播放。真实 `startPeriodicBeamSkill → tickBeamAttack` 用例确认声音不覆盖受影响的远处玩家。

命中声移到各锁定落点，保留本体的前摇/口部声，不修改“朝地面”设计或全设施所有声音的音量。自动验证播放入口、音效位置和传播范围，不代表已在客户端听过声音，也不能证明所有近距离无声报告都来自同一问题。

### 尸山特殊攻击：地面技能却要求三维准星选中目标

初次宽体用例没失败，不能算复现。改用窄体目标：施放者移动后、目标在正前方4格，抬头85度，旧三维准星查询选不到目标；真实 `use → 延迟回调` 未造成伤害。

选敌改为水平朝向、同层身体范围；保留4格选敌和落点3格范围，未增加伤害。计时归属于施放者，结算前复核原目标仍有效、同维度、前方范围；保留遮挡及合法异想体战斗状态。墙后、背后、另一层负面对照不受伤。未全局修改所有武器的视线查询。
