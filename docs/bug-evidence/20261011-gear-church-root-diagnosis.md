## 无损高度查询优化

当前原版噪声生成器每列分别调用WORLD_SURFACE_WG与OCEAN_FLOOR_WG，内部重复创建并插值同一噪声列。

小样本（48比较）先观察到两次独立查询150ms、一次完整列80ms；随后扩大到seed0/1/2共1152次、440次水面比较，数值全部相等。交替测试顺序、排除各seed第一轮预热后，原两次查询4245ms、完整列2329ms。无速度阈值作为断言，仅作本机局部基准，不宣称完整选址或所有机器获得同等收益。

证据：`W/run-gear-church-column-differential-20261011-a/gametest.log`，1/1通过。

生产采用单次getBaseColumn，按原Heightmap谓词读精确两个高度；只缓存两个int、不保存384层数组，缓存属于单次terrain/context，无全局跨世界状态。仅对确切原版NoiseBasedChunkGenerator启用；其他生成器及其子类仍调用原getBaseHeight，尊重自定义覆盖。不会加载真实区块、修改地形/实体或取消逐列验证。

新增生产GameTest直接比较terrain()与原版两高度查询，覆盖同1152水陆混合列及反向缓存读取；另用自定义生成器子类返回独立高度，确认不绕过其覆盖。`W/run-gear-church-orientation-and-heights-20261011-a`中实际通过。
